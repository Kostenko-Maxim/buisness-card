# Сайт-визитка

## SEO и публикация

`npm run build` создаёт готовые HTML-страницы на русском (`/`) и английском
(`/en/`), а также `dist/robots.txt` и `dist/sitemap.xml`. Публикуйте всю папку
`dist`: текст портфолио доступен поисковым роботам без выполнения JavaScript.
React подключает интерактивность к уже готовой странице.

Домен и метаданные находятся в `scripts/seo.mjs`. При смене домена обновите
`siteUrl` и пересоберите проект: canonical, hreflang, Open Graph, JSON-LD и карта
сайта используют этот адрес. В `vercel.json` настроены перенаправления дублей;
несуществующие страницы больше не перенаправляются на главную.

После публикации подтвердите владение доменом в Google Search Console и
Яндекс Вебмастере, добавьте `https://maxim-kostenko.ru/sitemap.xml` и запросите
переобход главной страницы и `/en/`. Коды подтверждения доступны только владельцу
аккаунта; после получения их можно добавить через DNS или метатеги.

Официальные рекомендации по предварительной генерации HTML:
https://developers.google.com/search/docs/crawling-indexing/javascript/javascript-seo-basics

## Локальный запуск

```sh
npm install
npm run dev
```

## Форма обратной связи

Форма в разделе контактов отправляет имя, email и предложение через FormSubmit
на `maxim.kostenkoo@yandex.ru`. Кнопка «Связаться» на первом экране ведёт к форме.
Ключи API и пароль почты не требуются.

Перед использованием отправьте форму один раз с запущенного сайта и подтвердите
адрес по ссылке в письме FormSubmit. После активации отправьте ещё одно предложение
и проверьте получение письма, включая папку «Спам». При переходе на другой домен
сервис может запросить повторную активацию. Локально открывайте сайт через Vite,
а не как файл `index.html`.

Сообщение об успехе означает принятие заявки сервисом, а не подтверждение доставки
в почтовый ящик. При ошибке текст сохраняется для повторной отправки.

Документация: https://formsubmit.co/ и https://formsubmit.co/ajax-documentation.
