# Сайт-визитка

## Локальный запуск

```sh
npm install
npm run dev
```

## Форма обратной связи

Форма в разделе контактов отправляет имя, email и предложение через FormSubmit
на `maxim.kostenkoo@yandex.ru`. Кнопка «Связаться» на первом экране ведёт к форме.
Ключи API и пароль почты не требуются.

Перед использованием отправьте форму один раз с запущенного сайта и подтвердите
адрес по ссылке в письме FormSubmit. После активации отправьте ещё одно предложение
и проверьте получение письма, включая папку «Спам». При переходе на другой домен
сервис может запросить повторную активацию. Локально открывайте сайт через Vite,
а не как файл `index.html`.

Сообщение об успехе означает принятие заявки сервисом, а не подтверждение доставки
в почтовый ящик. При ошибке текст сохраняется для повторной отправки.

Документация: https://formsubmit.co/ и https://formsubmit.co/ajax-documentation.
